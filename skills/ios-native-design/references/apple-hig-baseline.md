# Apple HIG baseline

Use this reference before choosing a visual style.

## Operating principles

Current Apple design guidance emphasizes purpose, agency, responsibility, familiarity, flexibility, simplicity, craft, and delight.

For agent work, translate them into these defaults:

- **Purpose** — every visible element must earn its place.
- **Agency** — actions are understandable and reversible where possible.
- **Familiarity** — reuse interaction models iPhone users already know.
- **Flexibility** — adapt to device, content, locale, and accessibility settings.
- **Simplicity** — remove unnecessary decisions and chrome without hiding essential actions.
- **Craft** — spacing, type, icons, states, copy, and motion all matter.
- **Delight** — create it through useful feedback and coherent behavior, not decoration alone.

## Two-layer model

### Platform / functional layer
Navigation, tabs, controls, sheets, menus, search, alerts, standard interaction.

Prefer system patterns here.

### Product / content layer
Content, data visualization, illustration, photography, editorial composition, product-specific objects.

Allow more brand expression here.
